## 修复：预览接口「未登录」（13:20）
用户反馈「发票管理页面点击预览提示未登录」。实测定位根因：
- 报销后端预览接口 `reimbursements/[id]/file` **有鉴权守卫**(getCurrentUser)，缺 token 返回 401 `{"error":"未登录"}`。
- 原预览用 `<a href>` / Button href 直接跳转，浏览器**不发 Authorization 头** → 命中 401。发票后端预览接口**无鉴权**，所以发票页本不该报错；用户实际是在报销管理页点「查看原文件」触发的（新手易混发票/报销）。
- 修复：`src/utils/openFilePreview.ts` 用 fetch 带 token 下载 blob + URL.createObjectURL 打开新标签页，替换三处预览入口（发票列表 index.tsx、发票详情 InvoiceDetailDrawer.tsx、报销详情 ReimbursementDetailDrawer.tsx）。tsc 0 错误，curl 实测裸请求 401 / 带 token 200+xlsx 验证根因与修复。
- ⚠️ 经验：凡后端有鉴权的文件预览，前端**绝不能**用裸 `<a href>` 跳转，必须 fetch 带 Bearer token。
